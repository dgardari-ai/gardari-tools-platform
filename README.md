# Платформа инструментов Гардари

[Открыть платформу](https://dgardari-ai.github.io/gardari-tools-platform/)

Версия **2.0 — рабочая демонстрация дизайна**, технический выпуск **2.0.0-preview.8**, 8 ноября 2026 года.

Новая версия продолжает разработку Платформы. Прежняя база 1.0 сохранена в истории и метке `v1.0.0`.

Каталог 13 авторских инструментов Дениса Гардари для исследования, мышления, моделирования и совместной работы с ИИ. Внутри — описания, варианты применения и рабочее окно для подготовки запросов.

Сейчас доступны ознакомительные файлы. Регистрация, подписки, платежи и автоматическая установка полных инструментов пока не подключены.

Этот репозиторий содержит опубликованную сборку сайта. Разработка, визуальный редактор, рабочие материалы и история ручных правок хранятся отдельно. Сайт размещён на GitHub Pages.
