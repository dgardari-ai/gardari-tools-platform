# Платформа инструментов Гардари

[Открыть временную версию](https://dgardari-ai.github.io/gardari-tools-platform/)

Версия **2.0 — рабочая демонстрация**, технический выпуск **2.0.0-preview.21**, 17 ноября 2026 года.

Новый дизайн собран по авторскому макету Affinity: тёплый основной фон, светлые карточки, фиолетовые акценты, общая сетка, компактное независимое меню и тёмные рабочие панели. Сохранены13 инструментов, полные описания, локальная подготовка запросов,6 предварительных программ обучения, избранное, видеокомментарии и подвал.

Регистрация, платежи, подписки и автоматическая установка полных инструментов пока не подключены. Рабочее окно составляет запрос локально; исследование выполняется в выбранной пользователем ИИ-среде.

Компьютерная главная открывается принятой анимацией: иллюстрация собирается из цветных форм, появляются фраза и контур; нижние разделы раскрываются при прокрутке. Предусмотрено неподвижное состояние при сокращённом движении. Рабочая телефонная версия принята: она показывает статичную композицию, полноширинные полосы и подвал, отдельные действия меню и каталога, удобный вход в кабинет. Все13 развёрнутых страниц инструментов и6 учебных материалов используют общий принятый шаблон. Подвалы компьютера и телефона собраны по актуальному Affinity; общий список называется «Наши ресурсы».

После входной сборки наведение на компьютерную иллюстрацию оживляет флаг, молотки и фигуры. При удержании движение повторяется, после ухода завершается цикл. Телефонная композиция и режим сокращённого движения сохраняют неподвижный рисунок.

Уточнены стрелки и маркеры, отступы карточек, форма кнопок кабинета и интервалы ресурсов. Меню учитывает безопасную область экрана iPhone. На компьютере маркеры разделов мягко пульсируют; при сокращённом движении остаются неподвижными.

Этот репозиторий содержит опубликованную сборку. Разработка, редактор, история ручных правок и рабочие материалы хранятся отдельно. Временный сайт размещён на GitHub Pages.
