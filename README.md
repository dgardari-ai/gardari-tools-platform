# Платформа инструментов Гардари

[Открыть временную версию](https://dgardari-ai.github.io/gardari-tools-platform/)

Версия **2.0 — рабочая демонстрация**, технический выпуск **2.0.0-preview.16**, 16 ноября 2026 года.

Новый дизайн собран по авторскому макету Affinity: тёплый основной фон, светлые карточки, фиолетовые акценты, общая сетка, компактное независимое меню и тёмные рабочие панели. Сохранены13 инструментов, полные описания, локальная подготовка запросов,6 предварительных программ обучения, избранное, видеокомментарии и подвал.

Регистрация, платежи, подписки и автоматическая установка полных инструментов пока не подключены. Рабочее окно составляет запрос локально; исследование выполняется в выбранной пользователем ИИ-среде.

Главная открывается принятой анимацией: иллюстрация собирается из цветных форм, появляются фраза и контур; нижние разделы раскрываются при прокрутке. Предусмотрено неподвижное состояние при сокращённом движении. Мобильная версия и открытая страница инструмента продолжают развиваться отдельно.

Этот репозиторий содержит опубликованную сборку. Разработка, редактор, история ручных правок и рабочие материалы хранятся отдельно. Временный сайт размещён на GitHub Pages.
